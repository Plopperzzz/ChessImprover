Batch analysis

Full runs the same Maia Elo sweep as the panel below, on every game in the batch — that's what fills in Progress. It uses a coarser Elo step in batch (Settings) so a long run stays affordable, and steps the board through each game as it goes.

Elo estimate (this game)

Sweeps the selected game only, which is far too little data to trust on its own — use it to see the shape of one game's curve, and Progress for your actual strength. For many games at once use Batch analysis above in Full mode; it runs this same sweep per game.

Which games

Bullet and rapid measure different things, so both panels below fit only what you pick here. Narrowing re-fits the cached sweep scores — no engine runs — but a smaller pool means a wider interval, which the panels say plainly rather than leaving you to notice.

Your strength

One fit over every position from every game with a stored sweep, in whatever slice of the library is picked above. A single game is only ~25 of your moves and lands within about ±180 Elo of the truth, so this is still the number to act on. Re-fits cached scores, so it never runs an engine.

Lichess puzzle database

Lichess publishes every one of its puzzles — several million, each with themes and a rating measured against real solvers. Importing all of it takes a while and about a gigabyte of disk, so the filters below let you take a band around your own rating instead. Re-importing later adds to what you have rather than starting over.
